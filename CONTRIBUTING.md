# Contributing to PharmaFlow

## Branches

- `main` — always stable; changes arrive by pull request only.
- `feature/KAN-<n>-<short-name>` — new work
- `fix/KAN-<n>-<short-name>` — bug fixes
- `docs/KAN-<n>-<short-name>` — documentation

## Commits

Reference the Jira issue key:

```
KAN-12: add interview guide to docs
```

## Pull requests

- Link the Jira issue.
- Describe what changed and why.
- CI must pass (once configured).
- At least one review before merging (when the team grows).

## Evidence rule

Product requirements must link to a **Validated** research finding in Notion. Code or features that are not traceable to a validated need should not be merged.
